# VP Minesweeper

A standalone browser Minesweeper game. The published site is in `public/` and uses no build tools or external services.

## Publish with GitHub Pages

This repository includes a GitHub Actions workflow that deploys `public/` whenever changes are pushed to `main`.

1. Push this project to a GitHub repository.
2. In the repository, open **Settings → Pages** and set the source to **GitHub Actions**.
3. After the workflow succeeds, GitHub will show the public site URL in the Pages settings and deployment.

GitHub Pages sites are public. With GitHub Free, the repository also needs to be public.
